# ICASSP 2027 Submission Package

This directory contains the ICASSP-format manuscript for the Relational-Orbit TTRL study: four pages of main text followed by one references-only page.

## Files

- `main.tex`: identified, non-anonymous manuscript using the official `spconf.sty` format.
- `build/shen.pdf`: submission-ready five-page Letter PDF; references begin on page 5.
- `references.bib`: bibliography database used with `IEEEbib.bst`.
- `spconf.sty`, `IEEEbib.bst`: official ICASSP paper-kit files.
- `figures/drawio/ro_pipeline.pdf`: corrected vector workflow schematic used as Fig. 1; editable source is `figures/drawio/ro_pipeline.drawio`.

## Before upload

1. Confirm the final author order, affiliations, and email addresses in `main.tex`.
2. Enter Yujie Shen's ORCID as `https://orcid.org/0009-0009-0447-9913`.
3. Enter Haowen Chen's ORCID as `https://orcid.org/0000-0002-4777-7525`.
4. Enter a complete mailing address for each author in the submission system.
5. Ensure that the author order, affiliations, email addresses, corresponding-author designation and ORCID records exactly match the online submission form.
6. Select the most appropriate ICASSP review category; the current scope is closest to machine learning and generative-AI methods, subject to the final category list.
7. Recheck arXiv-only technical reports for newer archival versions immediately before upload.

Project repository: <https://github.com/JJayshum/RO-TTRL>

The manuscript intentionally reports effect sizes and sample sizes without numerical 95% confidence intervals in the main tables. Full uncertainty calculations and raw records remain in the repository supplementary outputs.
